# codegen-quiver

A collection of installable skills for coding agents.

Each skill is a self-contained unit that extends agent capabilities — covering domains like data engineering, ML, backend development, analytics, and more. Skills are designed to be dropped into agent frameworks and invoked on demand.

## Structure

Skills are organized by domain. Each skill includes the prompt, any supporting configuration, and usage instructions.

## Usage

Install a skill into your agent by following the setup instructions in its directory. Skills are invoked via slash commands (e.g. `/skill-name`).
